🔧 Инструмент загрузки шрифта

Инструкция:

  1. Нажмите кнопку "Скачать шрифт"
  2. Файл автоматически загрузится на ваш компьютер
  3. Поместите файл Reborn-Technologies.ttf в папку public/fonts/ вашего проекта
  4. Готово! Шрифт заработает на сайте

Альтернативный способ (через консоль браузера F12):

// Скопируйте этот код в консоль браузера (F12)
fetch('/fonts/Reborn Technologies.ttf')
  .then(r => r.blob())
  .then(blob => {
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = 'Reborn-Technologies.ttf';
    a.click();
    URL.revokeObjectURL(url);
    console.log('✅ Шрифт скачан!');
  })
  .catch(err => console.error('❌ Ошибка:', err));
