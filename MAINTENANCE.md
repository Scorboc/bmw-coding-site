# Самостоятельный запуск BMW-сайта

Сайт не использует API, CDN, редактор и виджеты poehali.dev. Изображения скопированы в public/media, шрифт сохранён в public/fonts. CSS, композиция, карточки и оформление сохранены. Удалены внедрения старого хостинга. Учёт просмотров теперь ведёт собственный сервер без записи IP и текста диалогов.

## Запуск

Нужен Node.js 24 или новее с node:sqlite.

```sh
npm ci
npm run setup
npm run dev
```

setup создаёт .env.server.local со случайным ключом администратора и не печатает ключ. Существующий файл не перезаписывается. Ключ из этого локального файла используется для входа в /admin; в браузере хранится только в памяти вкладки, не localStorage. Файл не попадает в Git. Dev запускает API на 127.0.0.1:5190 и прокси /api в Vite.

Для единого production-сервера:

```sh
npm run build
npm start
```

Адрес по умолчанию http://127.0.0.1:5187. В Windows можно также открыть start-local.cmd из папки проекта. Пока окно сервера открыто, сайт работает; после остановки процесса или перезагрузки компьютера его нужно запустить снова. Автозапуск Windows не настроен. Для внешнего хостинга нужны HOST/PORT, HTTPS через reverse proxy и постоянное хранилище. Одного GitHub Pages недостаточно: необходим работающий Node-сервер.

## Собственная база

SQLite: .private/site.sqlite. При первом запуске импортируются 275 записей из data/chiptuning.csv (251 опубликованная) и 114 кодов ошибок из SQL-миграций, подготовленных npm run snapshot в data/catalog-seed.json. Это исходные данные репозитория, а не выгрузка текущей БД прежнего хостинга. Исторические просмотры и отсутствующие изменения не восстановлены. Цены из исходных файлов нужно актуализировать у владельца. Неизвестные цены Stage 2 не предлагаются как нулевые.

После инициализации база не пересоздаётся даже при удалении всех записей. Административные изменения сохраняются в SQLite. Публичного устаревшего JSON fallback нет: при отказе собственного API показывается ошибка, а удалённые/скрытые записи не возвращаются из старой копии.

Резервная копия: npm run backup, файл появляется в .private/backups. Для восстановления остановить сервер, сохранить текущие файлы базы, заменить БД проверенной копией и запустить сервер. Не менять файлы работающей БД. Реальную выгрузку со старого хостинга, если она будет получена, импортировать отдельно после резервной копии.

CSV в админке скачивается из собственной БД, не отправляется в чужой GitHub. Кавычки, запятые и переносы поддерживаются. Импорт предварительно валидирует все записи и сохраняет их одной транзакцией. Без ключа администратора минимум 32 символа административный доступ закрыт. Публичные API исключают черновики. База, секреты, исходники backend и seed-файлы не выдаются сервером.

## AI

Локальный режим в .env.server.local:

```dotenv
AI_PROVIDER=ollama
AI_MODEL=qwen3:4b
```

Нужен запущенный Ollama с установленной моделью; стандартный адрес http://127.0.0.1:11434. Веса модели не хранятся в Git. Скорость и качество зависят от компьютера и модели. Режим think:true отделяет внутреннее рассуждение от ответа: клиенту выдаётся только message.content. Используется максимум 2048 токенов генерации и 120 секунд ожидания. Если модель не успела выдать ответ, сервер сообщает ошибку, не подменяет ответ рассуждением. Настройка режима: https://docs.ollama.com/capabilities/thinking .

Для прямого платного провайдера вместо Ollama: AI_PROVIDER=polza, AI_BASE_URL=https://api.polza.ai/api/v1, AI_MODEL=openai/gpt-4o-mini и POLZA_AI_API_KEY на сервере. Платформа старого хостинга не участвует. Локальный режим не требует этого ключа. Клиент не выбирает произвольный сервер/модель; запросы AI ограничены по размеру, частоте и длине ответа. Ответы не заменяют диагностику автомобиля и не прошли проверку всей технической достоверности.

## Проверки и контейнер

```sh
npm run test:server
npm run typecheck
npm run lint
npm run build
npm run backup
```

Серверные тесты используют изолированную SQLite, проверяя доступ, мутации, черновики, сохранение при перезапуске, поиск, новую статистику, CSV и запрет секретных файлов. Старый Python-backend оставлен как архив; npm start его не запускает. Неиспользуемый VIN-калькулятор ServicesCalculator не подключён к интерфейсу и не является действующей функцией: самостоятельный VIN-декодер не добавлен.

Dockerfile готовит Node-сервер с постоянным volume /app/.private и серверными переменными окружения. Сборка Docker отдельно не проверена. Если Ollama работает вне контейнера, укажите доступный из контейнера AI_BASE_URL: 127.0.0.1 внутри контейнера означает сам контейнер.

Telegram, карты и Google Fonts остаются внешними сервисами, независимыми от прежнего хостинга. Внешняя публикация, DNS/HTTPS, автозапуск после перезагрузки Windows и нагрузочное тестирование в эту локальную проверку не входят.
