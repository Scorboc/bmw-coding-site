# Запуск и серверные настройки

Внешний вид сайта сохранён. Исправления не заменяют развёртывание серверных функций.

## Локальный запуск

```sh
npm ci
npm run dev
```

Проверки:

```sh
npm run typecheck
npm run lint
npm run build
python -m unittest discover -s backend/chiptuning-data -p test_auth.py -v
```

`npm run dev` и `npm run build` пересобирают справочную копию командой `npm run snapshot`.

## Недоступность прежних API

16.10.2026 оба прежних адреса (каталог и AI) вернули HTTP 402 с сообщением об исчерпании лимита poehali.dev. Изменение GitHub-репозитория не меняет подписку, доступы, базы данных или уже развёрнутый код на платформе.

При ошибке публичных GET-запросов каталог использует `public/data/catalog-snapshot.json`: 251 запись чип-тюнинга со статусом `1` из `data/chiptuning.csv` и 114 кодов из SQL-миграций V0022–V0024. Неопубликованные записи исключены. Это справочные данные из исходников, а не текущая выгрузка рабочей БД и не подтверждение актуальных цен. Каталог показывает соответствующее предупреждение. Цен Stage 2 в CSV нет, поэтому снимок не предлагает Stage 2. Запрос заказа по снимку содержит просьбу подтвердить цену.

Подмена не применяется к административным операциям, аналитике, POST и AI. Статистика и ответы AI не выдумываются. Поиск неизвестного кода различает отсутствие кода в справочной копии и недоступность онлайн-базы.

## Подключение серверов

1. Развернуть обновлённый `backend/chiptuning-data/index.py` с его зависимостями и PostgreSQL; сохранить/восстановить реальную БД отдельно. Миграции содержат начальные данные и не являются бэкапом текущей рабочей базы. Существующую БД не заменять начальными данными.
2. В окружении **сервера** задать `ADMIN_API_TOKEN`: случайный секрет не короче 32 символов. Не публиковать его и не добавлять в `VITE_*`. При отсутствии или коротком секрете сервер отклоняет административный доступ с 503. Для обычной публикации использовать HTTPS.
3. Настроить `DATABASE_URL`. Для необязательной синхронизации CSV задать серверные `GITHUB_TOKEN`, `GITHUB_REPO_OWNER=Scorboc`, `GITHUB_REPO_NAME=bmw-coding-site`; токен должен иметь доступ только к нужному репозиторию. Адрес исходного владельца больше не зашит в синхронизацию.
4. Для функции AI `backend/extensions/chatgpt-polza/chatgpt/index.py` нужны отдельный сервер и `POLZA_AI_API_KEY`, если используется предусмотренный кодом провайдер. Рабочий лимит провайдера/платформы проверять отдельно. Реальный ключ не помещать во frontend.
5. Скопировать `.env.example` в `.env.local` и задать только публичные адреса `VITE_DATA_API_URL`, `VITE_AI_API_URL`, при необходимости `VITE_SERVICES_API_URL`. Перезапустить dev-сервер или пересобрать сайт. Пустой `VITE_DATA_API_URL` намеренно оставляет админку закрытой: сайт не отправляет административный ключ на прежний сервер с неподтверждённой защитой.
6. Проверить на развернутом сервере: анонимные `?admin=1` и административные POST отклоняются, корректный ключ разрешает административный доступ, публичные `action=variants/bodies/engines/get_error/get_popular_errors` работают. Запись/синхронизацию сначала проверять в тестовой БД и тестовом репозитории.

Ключ администратора вводится при входе и остаётся только в памяти вкладки. `sessionStorage.admin_auth` больше не используется. После полной перезагрузки потребуется новый вход. Обновлённый код должен быть развёрнут на сервере: одна публикация frontend не защищает старую серверную функцию.

Для статического хостинга с BrowserRouter требуется fallback неизвестных путей на `index.html`. GitHub Pages сам по себе такой fallback для всех маршрутов не предоставляет. Публикация/смена домена в этом исправлении не выполняется.

## Границы проверок

Локально проверены чистая установка зависимостей, TypeScript, production-сборка, браузерные переходы/калькуляторы и изолированные тесты доступа. Lint проходит без ошибок; 6 предупреждений касаются Fast Refresh в стандартных UI-компонентах. Они не меняют выполнение production-кода.

Серверные тесты используют заглушки БД и HTTP: реальные заявки, записи в рабочую БД, синхронизация CSV, платная генерация AI и развёртывание не выполнялись. Защита старого опубликованного backend не изменена до его отдельного обновления. Достоверность автомобильных рекомендаций и актуальность цен не проверялись.
